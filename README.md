# Vinci — Landing page (Vue 3 + Motion for Vue)
1. `npm install`
2. `cp .env.example .env` puis renseigner les 3 clés EmailJS
3. `npm run dev`

Template EmailJS : variables `{{form_type}} {{name}} {{email}} {{phone}} {{service}} {{budget}} {{deadline}} {{services}} {{message}}`.

## Images des réalisations
Les aperçus actuels (`public/img/works/*.svg`) sont des maquettes génériques créées pour ce projet (aucun droit à gérer).
Pour les remplacer : déposez vos captures dans `public/img/works/` (ex. `nozam.jpg`, ratio 3:2) puis modifiez le champ `image` dans `src/data.js`.
